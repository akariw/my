# Mes Tâches

Une application de liste de tâches simple, en HTML/CSS/JavaScript pur (aucune dépendance).

## Fonctionnalités

- Ajouter, cocher et supprimer des tâches
- Modifier une tâche par double-clic
- Filtrer : toutes / à faire / terminées
- Effacer toutes les tâches terminées
- Sauvegarde automatique dans le navigateur (`localStorage`)
- Thème clair / sombre automatique

## Lancer l'application

Ouvrez simplement `index.html` dans votre navigateur.

Ou avec un petit serveur local :

```sh
python3 -m http.server 8000
# puis ouvrez http://localhost:8000
```
